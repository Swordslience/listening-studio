# 英语听力工作台 · Listening Studio

Windows 原生听力准备工具与离线课堂播放器，源码基线 v2.4。适合将完整英语考试录音整理为“材料／遍次／句子”，无需切出大量小音频。

- 家里：导入完整 MP3 → 豆包录音文件识别2.0 → 自动分句和归组 → 波形微调 → 导出。
- 学校：离线点题、点句重听，连续播放，字幕显隐和字号调整。
- 原 MP3 保持完整；材料使用相对路径，整个文件夹可放 U 盘。
- 自动结果仍需试听核对；不承诺所有试卷都能准确识别题界和重复遍次。

## 分享定位与配置

本仓库分享应用源码和课堂使用思路，供研究、构建及进一步开发，首次不附公众运行包。项目采用 AI 辅助开发，使用现有音频组件和语音识别服务。按下方构建步骤生成程序后，再按 [配置说明](docs/首次配置.md) 填写自己的语音与存储授权，准备 FFmpeg，然后打开 MP3 点击自动处理。云识别和对象存储按服务商账号计费；学校播放不需要 API 或网络。

用法见 [简明说明](docs/使用说明.md)。程序不自带商业语音额度，不要求安装大型本地识别模型。

## 构建

Windows 10/11，.NET Framework 4.8。在仓库根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

输出在 `dist/家里处理器` 和 `dist/课堂播放器`。NAudio 依赖及许可随仓库提供。
源码仓库不带 FFmpeg 二进制。将所需 FFmpeg 放到 `tools/ffmpeg.exe` 再构建，脚本会复制到家里处理器；官方来源 https://ffmpeg.org/download.html 。第三方构建及源代码要求见 [组件说明](docs/开发与组件.md)。

## 版本与隐私

此仓库不含作者的 API Key、TOS 凭据、内部授权、私人音频或云任务记录。个人设置用 Windows 当前账户加密保存。豆包识别需要上传所选音频至用户自己的 TOS 私有桶；识别成功后尝试清理临时对象，失败时留下清理提示。

内部免配置分发通过额外的 `内部专用授权.json` 提供共享授权；该文件不属于开源仓库，不能提交到 GitHub。公开版未预设作者的在线更新地址；维护者可在 `src/UpdateIdentity.cs` 设置自己的更新源和签名公钥。
