# 公开版首次配置（只做一次）

内部版不用本说明。公开版使用者需要自己的火山引擎账号与服务额度。

## 1. 开通语音服务并创建 Key

打开 https://console.volcengine.com/speech/new/ ，进入服务管理，开通 **录音文件识别2.0**。本工具使用标准异步文件识别，不是聊天模型、声音合成或方舟聊天 API。

在语音控制台 API Key 页面创建语音 Key：
https://console.volcengine.com/speech/new/setting/apikeys?projectName=default

打开软件 → **模型 / API设置**：

| 项目 | 填什么 |
|---|---|
| 使用的识别服务 | 豆包2.0 |
| 豆包语音 API Key | 上面创建的语音 Key，不填 App ID |
| 豆包模型名／资源 ID | 2.0 模式下固定处理，无需更改 |
| 阿里相关项目 | 使用豆包时不用填 |
| 音频语言 | 高考录音含中文提示时选自动（中英混合） |

## 2. 配置 TOS

打开 https://console.volcengine.com/tos ，开通对象存储，创建一个 **标准存储、私有** 桶。名字自行取，记下地域。例如广州对应 `cn-guangzhou`。不要把桶设置为公共读或公共读写。

打开 https://console.volcengine.com/iam ，创建专用 IAM 用户和 Access Key。给它仅限本桶 `listening-studio/` 目录的上传、读取、删除权限。策略模板在 [tos-policy.example.json](tos-policy.example.json)，先把 `YOUR_BUCKET` 替换成自己的桶名，再创建自定义策略并绑定到专用用户。

回到软件 → **模型 / API设置** → **配置火山TOS（首次）**：

| 软件字段 | 填什么 |
|---|---|
| 私有桶名称 | 自己创建的桶名，不含 URL 或目录 |
| 桶所在地域 | 与桶实际地域一致 |
| TOS AccessKey ID | IAM 专用用户创建的 Access Key ID |
| TOS SecretAccessKey | 同一对密钥中的 Secret Access Key |

保存存储配置 → 回上级窗口勾选 **记住密钥** → 保存。语音 Key 与 TOS 的 AK/SK 是两套不同凭据，不能互换。

## 3. 第一次使用

确认家里处理器目录有 `工具/ffmpeg.exe`。若自行从源码构建且未放入，请从官方来源下载后放到此位置： https://ffmpeg.org/download.html 。

打开完整 MP3 → 自动处理 → 确认使用额度 → 等待生成列表。建议先用短音频验证自己的服务权限。只听已处理的材料时，无需调用语音服务。

## 常见问题

- 语音服务权限或余额错误：检查是否开通录音文件识别2.0、语音 Key 对应账号和可用额度。
- TOS HTTP403：检查桶、地域、AK/SK，以及策略是否绑定到创建这对密钥的用户；不是充值就能解决。
- 提示缓存／原任务：重开同一个 MP3，点击自动处理恢复；不要连续点击重新识别。
- 换电脑：公开版的本机加密设置不能直接迁移，需要重新填写；学校导出的播放器不需要填写。
