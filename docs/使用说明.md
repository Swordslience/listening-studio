# 简明使用说明

1. 打开完整 MP3 → 自动处理。公开版首次先配置 API，内部版已预置授权。
2. 左侧选题目和遍次，右侧点句子试听。核对单句时先关连续播放、循环。
3. 不准就拖波形蓝边界；用“此处分开／合并下句”修分句，文字选中按 F2 改。分组不对用“材料 / 分组”。保存修改。
4. 点“导出到学校”，把导出的整个文件夹带走；双击其中课堂播放器即可离线播放。

默认连续播放沿原录音继续到第二遍和后面的材料；只听一句就关闭连续播放。只听当前遍：关闭连续播放后点播放整段。显示字幕开关字幕，字＋／字−调字号。

断网后重开同一 MP3，点自动处理继续原任务。重新识别才会新做云识别；本地优化会用已有识别结果重做分句并替换当前编辑，先保留备份。
