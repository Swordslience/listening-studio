# 开发和组件

主程序使用 .NET Framework WinForms。云识别、TOS 上传、分句与归组、波形编辑、播放和更新代码在 src。

NAudio 2.2.1： https://github.com/naudio/NAudio/tree/v2.2.1 ，MIT。lib 为 NuGet 对应依赖，许可在 third_party。

FFmpeg 由家里端以独立进程调用，课堂端不使用。源码仓库不带该二进制。可从 https://ffmpeg.org/download.html 获取；Windows 构建参考 https://www.gyan.dev/ffmpeg/builds/ 。若对外分发带 FFmpeg 的运行包，须同时满足所用具体构建的许可及对应源代码提供要求；不能把 FFmpeg 重新标为本项目 MIT。所用本机构建原说明附在 third_party/FFmpeg-BUILD-README.txt。

本次提供的公开运行包为轻量包，不带 FFmpeg；用户按首次配置说明自行取得后放到工具目录。内部包带本机现有 FFmpeg，仅内部使用。

在线更新：配置 UpdateIdentity.Feed 和签名公钥。SHA256 只校验完整性，更新真实性由签名校验。私钥不可写进源码；公开仓库没有发布私钥或任何云端上传凭据。初始公开版的更新源为空，检查更新会给出说明，离线播放不受影响。

测试：build.ps1 -RunTests 可运行不依赖私人材料的通用归组测试。更多真实录音准确率和目标学校设备仍需人工验收。
